# Exposures

Ищет ограниченный список файлов репозитория, конфигураций, резервных копий и API-спецификаций.
Проверка активная, но read-only: только GET, без записи/удаления/загрузки. По умолчанию до 150 путей,
20 одновременно открытых задач, общий лимит запуска запросов берётся из `--rate-limit`.

Для каждого пути берётся случайный soft-404 baseline и максимум 16 KiB ответа. Одного `200 OK` недостаточно:
находка требует узнаваемой сигнатуры (`.git/HEAD`, env-пары, SQL-конструкции, ZIP magic и т. д.). В отчёт попадает статус и SHA-256 образца, не содержимое потенциально секретного файла.

```bash
mortyscan scan https://owned.example --active --i-own-this-target --modules crawler,exposures
```

Ограничение: сигнатурный скан не доказывает, что данные действительно секретны; просмотрите evidence и устраните публикацию файла.
