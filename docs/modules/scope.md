# Scope allowlist

`--scope-file FILE` принимает домены, IP-адреса, CIDR и wildcard `*.example.org`, по одной записи на строку.
Строки с `#` в начале — комментарии. Цель должна входить в allowlist, иначе запуск отменяется.

```text
# apex разрешает сам домен и его поддомены
example.org
192.0.2.0/24
# только поддомены, не apex
*.staging.example.net
```

HTTPX request-hook проверяет каждый запрос до отправки, включая редиректы и вспомогательные внешние HTTP API;
запросы к хостам вне allowlist блокируются. Поэтому некоторые пассивные сведения от сторонних API могут отсутствовать
при ограниченном scope. Nuclei и ARP-модуль пропускаются при активном scope-файле: внешний процесс и широковещательный LAN-скан не используют HTTPX guard и потому не могут дать ту же гарантию ограничения.
