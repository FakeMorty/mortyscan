# `enrich` — CVE enrichment

Модуль обогащает уже найденные CVE EPSS-оценкой и отметкой CISA KEV, а также может сопоставить версии зависимостей из уже обнаруженных публичных manifest-файлов с OSV.

## Включение

```bash
mortyscan scan example.com --enrich
```

`--enrich` — отдельный opt-in: в публичные базы уходят CVE IDs и координаты пакетов (`ecosystem`, package name, pinned version), но не URL цели, HTTP-заголовки, credentials или тела ответов. `--no-external` полностью пропускает модуль. Для обычного сканирования не требуется активное разрешение.

## Источники и ограничения

- EPSS: один пакетный запрос максимум на 100 CVE за запрос.
- CISA KEV: каталог кэшируется на 24 часа.
- OSV: версии извлекаются только из in-scope manifest-файлов, уже найденных `exposures`; проверяется максимум 40 закреплённых версий, не чаще 4 запросов в секунду.
- Кэш по умолчанию: `~/.cache/mortyscan/enrich/`; TTL 24 часа. Для тестов и изолированных запусков путь можно задать конфигурацией `enrich_cache_dir`.
- Если API недоступны или ответ некорректен, основное сканирование продолжается; в отчёт добавляется только сводное число обогащённых записей.

EPSS/KEV/OSV — внешние оценки и advisory, а не доказательство эксплуатабельности на цели. Перед remediation подтвердите фактическую версию и применимость уязвимости.
