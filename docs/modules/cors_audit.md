# CORS audit

`cors_audit` делает ограниченные GET/OPTIONS-проверки главной страницы и известных URL из краулера
(не более 12 endpoints). Отправляет тестовые `Origin` включая `null`, suffix-bypass и непроверенный поддомен,
а также безопасный GET preflight. Максимальная частота задаётся `--rate-limit`.

Состояние не меняется: POST/PUT/DELETE и переходы по внешним редиректам не выполняются. Если переданы `--cookie`
или `--header`, они прикладываются только к target origin и используются для проверки credentialed CORS.

Wildcard + credentials отмечается как misconfiguration среднего уровня: браузеры по стандарту блокируют такое сочетание,
поэтому находка сама по себе не доказывает чтение ответа из браузера. Поддомены нужно сверить с настоящей scope-политикой.
