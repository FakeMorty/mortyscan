# WAF fingerprint

Пассивно анализирует заголовки, cookie и короткий фрагмент главной страницы для узнаваемых сигнатур.
Никакие обходные пейлоады не отправляются. Результат записывается в `ScanContext.waf` и отчёт.

Fingerprint эвристический: отсутствие находки не означает отсутствие WAF, а наличие сигнатуры не подтверждает,
что защита включена или правильно настроена. `get_tamper_chain(waf_name)` возвращает рекомендации SQLMap для известных Cloudflare/ModSecurity/Akamai/F5 fingerprints; для неизвестного имени возвращается `space2comment`. Это только подсказки, не гарантия обхода и не разрешение на эксплуатацию.
